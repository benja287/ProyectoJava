Congreso de Agroecología — Backend (Grupo 1)

API Java: Servlets + JPA/Hibernate + MySQL. Equivalente servidor del proyecto React.

Prueba de la entrega 3 (ABM + DAO)

GET /test-persistencia — ejecuta todos los casos de prueba ABM sobre los DAOs.

Endpoints de referencia

  • GET /api/health — estado del servicio
  • POST /api/login — JSON: {"email":"...","password":"12345678"}
  • GET /api/trabajos — listar trabajos
  • POST /api/trabajos — enviar trabajo (JSON con autorId, titulo, etc.)
  • GET /api/circulares — circulares publicadas
