================================================================================
ETAPA 1 — CON DATOS DE PRUEBA (UsuarioMockService)
================================================================================

1) Crear proyecto (ya hecho):
   cd frontend
   npx @angular/cli@latest new jyaa-frontend --routing --style=css --skip-tests

2) UsuarioMockService (usuario-mock.service.ts):
   • Propiedad estática usuarios: Usuario[]
   • Métodos estáticos: listar(), buscarPorId(), alta(), setActivo(), baja()

3) Probar Etapa 1 sin backend:
   En src/environments/environment.ts poner:
     useMock: true
   ng serve
   Abrir http://localhost:4200

4) Recorrer la práctica:
   a) Inicio → enlaces a registro y homes de perfiles
   b) Registro → completar DNI, apellido, nombres, domicilio, género, email → Guardar
   c) Admin → Listado de usuarios → ver filas del mock
   d) Click Detalle → ver datos → Habilitar / Inhabilitar

================================================================================
ETAPA 2 — CON CAPA DE SERVICIOS REST
================================================================================

1) UsuarioService (usuario.service.ts):
   • @Injectable({ providedIn: 'root' })
   • Misma firma que el mock pero métodos de instancia
   • Inyecta HttpClient
   • Si useMock === false llama a la API Java

2) Componentes inyectan UsuarioService (no UsuarioMockService):
   constructor(private usuarioService: UsuarioService) {}

3) Endpoints REST usados (Entrega 4):
   GET    /api/usuarios?page=1&size=50     → PaginaUsuariosDTO.items
   GET    /api/usuarios/{id}               → UsuarioDTO
   POST   /api/usuarios                    → alta (nombre, apellido, email, password)
   PUT    /api/usuarios/{id}/activo        → { "activo": true|false }

4) Configurar desarrollo con proxy:
   proxy.conf.json ya apunta /api → http://localhost:8080
   ng serve  (lee proxy desde angular.json)

5) Probar Etapa 2 con backend:
   En environment.ts: useMock: false
   Levantar Tomcat con el WAR del backend
   ng serve
   Registro → POST crea usuario en MySQL
   Admin → listado trae usuarios reales de jyaa2026_bd1
