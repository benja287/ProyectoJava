# Segunda Entrega - Modelo de Objetos

Este directorio contiene la propuesta de modelado de la capa de logica de negocio para:

`Sistema de gestion del V Congreso Argentino de Agroecologia`.

## Contenido

- Clases Java del dominio en `src/main/java/ar/unlp/agroecologia/modelo/`
- Diagrama de clases en PlantUML: `diagrama-clases.puml`

## Exportar diagrama a PDF

Si tienen PlantUML instalado:

```bash
plantuml -tpdf diagrama-clases.puml
```

Eso genera `diagrama-clases.pdf`, que pueden entregar junto con las clases.
